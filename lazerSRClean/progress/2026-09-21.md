# 2026-09-21 — osu! 2026.920.0-lazer 대응: 참조 소스 갱신 + 차단 의도 확인 + 우회 대안 검증

osu! 2026.920.0-lazer부터 `osu.Desktop.csproj`에 `StartupHookSupport=false`(+`CETCompat=false`)가 들어가
`DOTNET_STARTUP_HOOKS`로 Hook이 아예 로드되지 않음(원인은 원격 세션에서 확정).

  - osu!.exe 직접 실행 + `DOTNET_STARTUP_HOOKS` → hook 안 돎(원인 재확인)
  - C로 만든 최소 호스트(`hostfxr_initialize_for_dotnet_command_line` → `hostfxr_set_runtime_property_value("System.StartupHookProvider.IsSupported","true")` → `hostfxr_run_app`)
    → **hook 돎**. 시점은 `Main` 이전, osu.Game 미로드(기존 StartupHook과 같은 시점), runtime 10.0.12, Satori coreclr에서도 정상
  - 안전장치: 테스트 hook이 즉시 `Environment.Exit`, 인자 `--debug-client-id=1`(Release에서 Main 첫머리에 throw)로 osu! 데이터에 닿지 않게 함
- 테스트 코드/바이너리는 스크래치패드에만 둠(프로젝트에 추가한 파일 없음)
