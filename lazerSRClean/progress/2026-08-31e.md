# 2026-08-31 (5차) — API 키 전면 제거

v6.8.1에서 도입한 API 키 방식이 근본 원인이었다는 게 밝혀짐: 키가 최초 등록 시점 유저네임에
영구 고정돼, 필터를 정확히 고쳐도 서버 기록은 계속 잘못된 이름으로 남는 구조였다. 리플레이
메타데이터에 이미 실제 플레이어의 osu! 유저네임이 들어있으므로(`ScoreInfo.RealmUser.Username`),
굳이 별도 키/등록 절차를 둘 필요가 없었다. **사용자 지시로 키 관련 코드 전부 제거.**

- ~~`src/auth.py`~~ 삭제. ~~`src/api/register.py`~~ 삭제. ~~`scripts/issue_key.py`~~ 삭제.
- ~~`src/db.py`~~ `users` 테이블에서 `api_key_hash`/`name` 제거, `osu_username` 하나로 단순화.
  `get_or_create_user()` 추가 - 있으면 찾고 없으면 그 자리에서 만든다.

  직접 읽어 `get_or_create_user`).
- ~~`src/api/presence.py`~~ 동일하게 키 제거, body의 `osu_username` 사용.
- ~~`src/app.py`~~ register 블루프린트 등록 제거.
- 배포 + DB 재초기화(스키마 바뀌어서 기존 파일 삭제 후 새로 생성) + 실제 리플레이로 키 없이
