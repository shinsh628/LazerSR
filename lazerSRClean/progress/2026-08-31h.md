## v6.11.1 — 해시 불일치 수정

실사용에서 리더보드가 계속 "기록 없음". 서버 로그 확인 → 요청은 정상 도착, `{"scores":[]}` 반환.
원인: 조회 패치가 `beatmap.MD5Hash`(32자 MD5)를 보내는데 업로드는 `ScoreInfo.BeatmapHash`
(64자 SHA-256)를 저장. 컬럼명 `beatmap_md5`지만 실제 SHA-256.

- ~~수정~~ `LazerSrLeaderboardFetchPatch`: `beatmap.MD5Hash` → `beatmap.Hash`. 6.11.1 태그.

## 미검증 (실사용 QA — 다른 PC RC)

- osu 안에서 토글 버튼이 헤더에 뜨는지, scope 드롭다운 비활성 되는지

- 국기 없음 / pp 빈칸은 의도된 것
